# The Coding Interview Prep Handbook

This repository contains the code from the book *The Coding Interview Prep Handbook* by Raydelto Hernandez.

You can acquire the book [here](https://www.amazon.com/Coding-Interview-Prep-Handbook-Structures-ebook/dp/B0DDJN4KVL).

Makefiles are provided in each chapter folder so that you can use any C++ compiler, such as g++ or clang++.

Once you have a C++ compiler installed along with the necessary build tools, you can use the `make` command by navigating to the appropriate chapter folder and specifying the target name you want to build. For example, to build the Bubble Sort code in Chapter 7, go to the `chapter_07` folder and run the following command:

`make bubblesort`

You can find all available build target names by opening and reading the Makefile located in each chapter folder.
